# 投资研究与多模型模拟项目

仓库：https://github.com/Haw-hao/invest ，主分支 main。

当前为文档和空模板阶段。A 股由用户人工执行，加密自动化为后续研究。尚未部署行情采集、策略或定时报告服务。

## 开始顺序

1. PROJECT_CONTEXT.md、TODO.md：范围与进度。
2. DATA_SOURCES.md、models/TEMPLATE.md：验证数据并冻结模型定义。
3. OPERATIONS.md、records/：信号、模拟执行与净值记录。
4. SIMULATION_RULES.md、PORTFOLIO.md：成交约束和核算。
5. daily/、WORKFLOW.md：输出、保存、发布和检查报告。
6. MOBILE_INSTRUCTIONS.md：复制到手机端投资项目指令。

AGENTS.md 是工作规则，DECISIONS.md 是研究决定，MODEL_CHANGELOG.md 保留模型版本变化。A-share/ 和 crypto/ 分别存对应市场研究。

公开仓库中不填写真实账户金额、持仓、成交、钱包地址或凭证。private/ 仅为本机排除路径，不是手机共享方案；私有资料同步待配置。
